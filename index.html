Logging in records your name and login time so faction leadership can see who's using the tool — your key itself is never stored anywhere except your own browser.

WWL·03 / leadership tools

Chain payout — non-war hits

Add chain IDs, combine them, and pay members per non-war hit (total hits − war hits). Needs a leader key with faction chain-report access.

🔒 Leaders only

This tool reads faction chain reports, which the Torn API only allows for members with the API Access faction permission. Your key doesn't have it — if you think you should, ask your leadership to enable it for your position in the faction's permission settings. Everything else in WorldWideLabs works for you as normal.
