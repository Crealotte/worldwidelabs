WWL·06 / organized crime fit

OC Fit Tracker

Your predicted Checkpoint Pass Rate for every role that's currently open in one of your faction's crimes, straight from Torn's API — this shows what you'd score if you joined, not a record of what you've actually played. Builds itself over time: once a role's been open once, it stays here (marked as cached, and dropped automatically after a long stretch unseen) until it opens again. Shared with faction leadership to help build teams — see the login screen for details.

WWL·06b / leadership tools

🧩 OC Team Builder

Every scenario your faction has ever seen, live or cached, browsable the same way as the personal tracker. Assign members to roles and save a plan — members still need to click Join in Torn themselves (Torn's API is read-only, so this can't do that part for you), but this takes the guesswork out of who goes where.

🔒 Leaders only

The Team Builder needs the same API Access faction permission as Chain payout.

WWL·07 / overseas stock

Overseas Stock

Live foreign stock and real profit per item, sourced from YATA's shared community database — the same one nearly every Torn travel tool reads from. Every country's items in one sortable, filterable list — pick which countries to include, hide anything at a loss, and sort by profit, price, or stock. Each row shows exactly how old its data is, since that's the actual reason these tools sometimes look wrong: it's only ever as fresh as the last person who happened to land there.
