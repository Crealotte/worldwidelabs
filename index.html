WWL·03 / leadership tools

Chain payout — non-war hits

Add chain IDs, combine them, and pay members per non-war hit (total hits − war hits). Needs a leader key with faction chain-report access.

🔒 Leaders only

This tool reads faction chain reports, which the Torn API only allows for members with the API Access faction permission. Your key doesn't have it — if you think you should, ask your leadership to enable it for your position in the faction's permission settings. Everything else in WorldWideLabs works for you as normal.

WWL·06 / ffscouter target finder

Target finder

Pulls Fair Fight and estimated stats from FFScouter, a free third-party service — not something we run ourselves. It uses the same Torn key you're already logged in with.

Checking your key with FFScouter…

One-time step: register with FFScouter

Target Finder is powered by FFScouter, a free, independent tool that estimates opponents' battle stats from crowd-sourced Fair Fight data. It isn't part of WorldWideLabs or Anthropic — it's a separate community service. Before we can use it, please open their homepage, read their Data Policy and Terms, then confirm below. This uses the same Torn API key you're already logged in with — nothing new to type.
